# 共通UI（03-1）

## 方針

上下の細いバーと中央の主役で構成する。明るい背景、読みやすい大きな文字、適度な角丸と明確な枠線を採用。参考画像の素材は使わない。

- PC：最大1120pxのゲーム領域。スマホ：幅いっぱいの縦長配置。600px以下で余白と操作配置を調整。
- 共通色は `src/index.css` のCSS変数に集約。青緑とミントの具体値は暫定で調整可能。
- ヘッダー：左にタイトルへ戻る矢印（既存の表示条件を維持）、右にアカウント入口。
- フッター：中央表示を切り替える遊び方と音の設定。本文に重ねず通常レイアウトに置く。
- 音の設定は初期OFF。localStorageに保存し、利用不可ならセッション中のみ保持。音源接続は後続タスク。
- ボタンと入力欄の基本形、ホバー・押下・フォーカス・無効状態を共通CSSで定義。
- 各画面固有のデザイン・実認証・対戦通信・BGMと効果音は後続タスク。

## 確認結果（2026-10-10）

- 既存の画面遷移テスト8件、TypeScript/Viteビルド、Lint成功。
- PCで上下バー、背景、基本スタイルを目視確認。
- ブラウザ幅320pxで認証・ランキング・ゲーム・結果、375pxでタイトル・戦績と遊び方を確認。測定した画面に横スクロールなし。
- ゲスト／仮ログイン表示、アカウント入口、戻る矢印のEnter操作を確認。
- 遊び方の再クリック／ヘッダーの戻る矢印で、元の画面と試合状態に復帰することを確認。画面切り替え時は見出しへフォーカス。
