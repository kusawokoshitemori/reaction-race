# 04. ゲーム画面UI

通信を行わない操作体験用モック。背景・かかし・木札は独自のSVG/CSSで描画しており、外部素材や有料素材は使用していない。キャラ画像の差し替えは GamePanel の game-dummy 部分で可能。

## 操作

1. ゲスト／仮ログイン → ゲーム開始 → 構える。
2. 2〜5秒のランダムな待機後に「!」が出る。
3. ページ内のどこでも左クリック／タップ、またはスペースキーで入力する。
4. 成功時は斬撃とかかしの分割演出を出し、木札に秒を小数3桁で表示する。
5. 「結果を見る」で結果画面へ。実測値をmsで表示し、固定の99人と比較したモック順位を出す。

戻る・アカウント・遊び方・音設定などの操作部品は反応入力から除外する。ブラウザのツールバーやページ外は入力対象ではない。スペース長押しのリピート・右クリック・複数タッチ・二重送信は除外。

## 状態

- waiting: 構える前。入力は記録しない。
- ready: 合図待ち。入力するとフライング。
- signal: 3秒間の入力受付。performance.now()によるブラウザ内の概算計測。
- submitted: 最初の入力が確定。約1.3秒の演出後にsettlingへ。
- settling: 成功・フライング・未入力の表示を保ち、結果ボタンを出す。

試合中にタブを隠す、または遊び方を開くと中断し、記録なしになる。ページ離脱・アンマウント時にはタイマーとイベント購読を解除する。再戦では前回タイムと演出をリセットする。OSの動きを減らす設定ではアニメーションを省く。

## モックの範囲

自分の反応時間のみ実測。他の99人、順位、レート変動は画面確認用。通信・募集処理・時刻同期・遅延補正・保存・不正対策は別タスク。音は既存の「準備中」のまま。

GamePanel のローカルタイマーが start / signal / timeout / settle を進める。通信実装時はこれらの進行と createDemoResult / createDemoStandings をサーバー通知に置き換える。計測開始はReactの合図DOM更新時であり、表示機器の遅延補正は行わない。同タイムはモック相手を先に並べる。

## 検証

- npm test: 入力期限の境界、フライング、中断、二重入力、実測値とランキングの一致、既存画面遷移。
- npm run build / npm run lint。
- ブラウザでスペース成功、クリック成功、結果への実測値引き継ぎ、再戦リセット、フライング連打、未入力を確認。
- 小画面用レイアウトを390px幅で確認。
