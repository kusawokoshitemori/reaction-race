## 計測と計算
受信時刻は08と同じく、WebSocketのメッセージ取得後、manager mutex取得直後、JSON解読より前にサーバーで記録する。タイマーと入力を同じmutexで直列化し、締切後や終了後に結果を上書きしない。OSのネットワーク到着時刻ではない。

ブラウザ標準のWebSocket Ping/Pongを利用し、端末時計やクライアント申告時間は使わない。200ms間隔でサーバーが予測不能なnonceを発行する。同時に未応答なのは1件、1秒で失効。異なるnonce・重複・期限超過のPongは標本にしない。各接続の最新64標本だけを保持する。

合図時に接続を固定し、合図前10秒以内に送受信が完了した標本と、settling開始後に送信した標本を使う。試合後は3秒で打ち切り、切断や応答欠落で試合が止まらない。別の接続の標本を混ぜず、再接続時に十分な標本がなければ参考記録になる。

前後それぞれ3標本以上が必要。直近最大5標本の最小RTTを代表値とする。どちらかの標本の最大・最小差、または前後の代表値の差が50ms超、あるいは代表値が500ms超なら不安定とする。この閾値は暫定値で実環境検証後に調整する。

合図から入力受信までには往路と復路が含まれるので、**半RTTではなくRTT全体**を引く。

```text
rawReactionMs = 入力受信時刻 − 合図時刻
correctionMs = min(試合前の最小RTT, 試合後の最小RTT)
reactionMs = rawReactionMs − correctionMs
```

補正が生の計測値を超える場合は0msの好記録に丸めず、不安定として順位対象外にする。ボットは通信しないため補正0。フライング・未入力の区分は変更しない。

成功かつ補正可能な人間とボットだけを昇順で順位付けする。同一の整数ミリ秒は同順位（1、1、3）。補正不能な人の記録を無理にボットと比較せず、rank:nullの参考記録として一覧末尾に表示する。画面上の参加者数は順位対象外も含む総数。

## 通信・表示・ログ
finished時のinput/resultsにはrawReactionMs、correctionMs、measurement、rankを追加する。
measurementはcorrected / unavailable / unstable / bot。失敗・未入力にはmeasurementを付けない。
reactionMsはfinished以前は暫定の補正前時間、finishedで補正後または参考時間になる。試合中は「補正前」、結果では「通信遅延を補正した記録」または「参考記録」と表示する。順位はサーバーが決定し、フロントでは再計算しない。

match measurementログには公開participant ID、試合ID、前後のRTT標本、補正前後の時間、補正量、計測状態、順位を記録する。トークン・nonce・Firebase UID・表示名は記録しない。DB保存・レート計算は今回の範囲外。

## 検証と限界
単体テストでは反応200msにRTT20ms／180msを加えた220ms／380msの入力を、どちらも200ms・1位に補正する。ボット250msは3位。計測不足、変動、RTT上限、期限切れ、再送、古い標本、補正が生計測値を超える場合も検証する。

TestSocketLatencyCorrectionでは実際のローカルWebSocket接続に、Pongの往復分と入力到着の往復分として20ms／180msの人工遅延を与える。200msの反応を送信し、前後RTT計測から確定結果まで検証する。OSスケジューリングの誤差を考慮し、補正後170〜230msを許容する。実機のネットワークをエミュレートした性能保証ではない。

残る限界:
- 08のサーバー合図から3秒という排他的締切を維持する。到着が締切を超えた入力は後から復元しないため、締切付近の回線差は残る。
- 前後の測定から分からない試合中だけの遅延急増、合図通知のキュー待ち、OS・mutex待ち、描画・入力機器の遅延は完全には取り除けない。
- 合図直前の先走り入力が合図後に到着するケースを完全には識別できない。補正が負になる場合は順位対象外にする。
- 最小RTTは一時的な待ち時間による過大補正を抑えるが、意図的にすべてのPongを遅らせるクライアントを完全には検知できない。信頼できる実機の反応時間を証明する仕組みではない。
- 補正後でも数msの順位差を厳密な実力差として保証しない。

公開後は同じ端末でWi-Fi／モバイル回線を切り替え、次に同じ回線で端末を切り替えて各30試合を記録する。rawReactionMs、reactionMs、前後RTT、参考記録率、端末・ブラウザ・入力機器を比較する。人間の反応のばらつきを含むため、機械入力による固定反応との比較も別に行う。公開環境・実機での検証は未実施で、Notion親タスクの実環境に関する完了条件はまだ満たしていない。
