# TASK-19：画面遷移

参照：[02. 画面遷移の実装](https://app.notion.com/p/3f3df60d21148121a67fd1eb86c325f2)。子タスク TASK-38〜41 に対応。

## 画面と導線

| 画面 | URL | 導線 |
| --- | --- | --- |
| ログイン | `#/auth` | 初回表示。メールアドレス・パスワード欄、ログイン、ゲストで続ける。どちらもタイトルへ |
| タイトル | `#/` | ゲーム開始、ランキング。右上のゲスト／プレイヤー名からログイン画面へ |
| ゲーム | `#/game` | 待機→合図待ち→入力→結果確定。共通ヘッダー左上の「←」で退出してタイトルへ |
| 結果 | `#/result` | 再戦で新しいゲームへ、タイトルに戻る |
| ランキング | `#/ranking` | 共通ヘッダー左上の「←」でタイトルへ |
| 戦績 | `#/history` | ログイン後のアカウント画面から移動。タイトルへ戻れる |

初回はログインまたはゲストの選択を必要とする。ゲスト選択後はログインしていなくてもタイトル・ランキング・ゲームへ進める。認証は画面確認用で、入力値を保存・送信しない。空欄でも仮ログイン可能。ログアウトと再読み込みで仮状態を消去し、ログイン画面へ戻す。

## ルーティング・ゲーム状態

ブラウザ標準のハッシュと hashchange を使用。静的配信でも直接アクセス可能。
ゲーム内の段階は同じURLで管理し、仮ボタンで進める。成功・フライング・未入力の仮結果を用意。実タイマー・判定・通信は後続タスク。

- 初回の直接アクセスはログイン画面へ置換遷移。
- 入口選択後、試合・結果がないURLや不明URLは理由付きでタイトルへ置換遷移。
- 未ログインで戦績を開くとログイン画面へ移動。
- 他画面への移動で仮試合から退出。戻る・進むでも退出済み試合は再開しない。
- 結果は再戦・ログアウト・再読み込みまで保持する。
- 実対戦での切断・復帰・複数タブ管理は後続タスクで実装する。
