# TASK-43: ランキングパネル

スタート画面と同じ背景・ヘッダー・フッターを保ち、中央にランキングを表示する。
フッターの「ランキング」ボタンで開閉する。背景や行のクリック、Escapeキーでは閉じない。
ブラウザ履歴と既存URLとの整合性のため、内部では `#/ranking` と `#/` を使う。
開くと見出し、閉じるとランキングボタンにフォーカスを移す。

- 仮データの1〜50位（順位・名前・レート）をパネル内でスクロール。
- ログイン時は自分の順位と行を表示。ゲスト時は本人の順位を表示しない。
- 個人レートとランキングで青緑の枠・淡い水色の面を共有。配色はレビュー対象。
- `RankingPanel` の `state` で success / loading / error を切り替え、success の空配列で記録なしを表示。
- 実画面は仮データの success 固定。読み込み・空・エラー・再試行はコンポーネントテストで検証。
- データはレート降順で渡す想定。取得・集計・本人照合は後続タスク12で接続。
